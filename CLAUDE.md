# Godot AmbientCG plugin — agent rules

Godot 4 editor plugin (GDScript) that searches ambientcg.com and downloads PBR materials and HDRIs into the project. Built in Godot 4.5.1; needs ≥4.4 (typed dictionaries). Main-screen plugins are deprecated as of Godot 4.8 dev4.

- All code is under `addons/` (`ambient_plugin.gd`, `plugin.cfg`, `gui/`, `global/`, `plugin_assets/`).
- Keep `.uid` files next to their scripts; Godot needs them.
- No test runner; verify in the Godot editor.
- ambientCG assets are CC0; the plugin is not affiliated with ambientCG — keep the legal notice in README.
